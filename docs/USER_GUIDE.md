# User guide

## Try it in 3 minutes (no sign-up)
1. Open the app → **Try the demo — no sign-up**. You get a private sandbox and a **Demo guide** (bottom right) that ticks off each step.
2. A risky AI-written Diwali ad is checked automatically: risk **100**, 7 findings. Each finding shows the rule, the approved fact (with validity dates and source) and a suggested fix. Click a highlight to jump to its finding.
3. Click **Apply 7 fixes**. Risk drops to **0**; **Purpose Guard** confirms the product, offer and call-to-action were kept.
4. Click **Submit**. The review page shows a **Next step** banner — click **Switch to Reviewer**, then **Approve**. A **Proof Certificate** appears.
5. Back on **Check**, try **Off-brand poster** (text read from the image with boxes, low-contrast text, missing logo, off-palette colours), **Hinglish** and **हिंदी**.
6. Switch to **Brand Admin** → **Brand Memory** → change *Maximum discount* to 10 → **Preview impact** shows which approved posts would now break.

## Roles
| Role | Can |
|---|---|
| Creator | check content, apply fixes, submit, contest medium/review findings with a reason, resubmit |
| Compliance | dismiss any finding with a reason, clear claims, request changes, reject |
| Reviewer | dismiss medium/review findings, approve (issues the certificate), request changes, reject |
| Brand Admin | edit Brand Memory, import brand books, upload logo/palette, preview impact, invite people, change roles |

In a demo sandbox you can switch between all four roles. In a team workspace you only see the roles your admin gave you.

## Team workspaces
- **Create a team workspace** (start with the demo brand or your own). You become Brand Admin with all roles.
- **Team → Invite people**: choose roles (optionally lock to an email) → copy the link → send it. The invitee creates an account (or signs in) and joins.
- **Four-eyes rule:** with 2+ members, nobody can approve content they submitted.

## Brand Memory
- **Import** a PDF/DOCX/TXT brand book. Found facts/terms/confidential items appear as pending candidates (old → new) — approve or reject each.
- **Change a fact / add a term / confidential term / toggle a rule** → **Preview impact** → **Apply change**. Every change creates a new Brand Memory version.
- **Logo** and **palette** are used by the poster checks.

## Checking content
- Paste text (English, Hindi or Hinglish) or upload **PDF / DOCX / TXT / PNG / JPG** (max 6 MB, 20,000 characters).
- **Confidential mode** sends nothing to any AI service (rules only).
- Medium/review findings can be **contested** with a reason; Insights uses these to find unclear rules.

## Certificates
- **Certificates** re-verifies the whole chain on every visit.
- **Is this the approved text?** — paste text to see if it exactly matches an approved version.

## When something goes wrong
- *“Waking up the server…”* — free hosting sleeps when idle; wait up to a minute.
- *AI busy / quota* — the check still runs with rules; the purple box says what was skipped. Try again in a minute.
- *Session expired* — demo sandboxes expire after 48 h idle; start a new demo.
